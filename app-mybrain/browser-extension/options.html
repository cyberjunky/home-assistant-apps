MyBrain

Connect to Home Assistant

The extension sends what you save to Home Assistant, the same way the phone app shares. It lands in the MyBrain of the person the token belongs to.

The address you open Home Assistant with in this browser. Nabu Casa's remote address works too.

In Home Assistant: your profile → Security → Long-lived access tokens → Create token. It must be an administrator's: only they may send events. The token stays in this browser.

Saving

  1. The MyBrain button in the toolbar saves the page you are on, with a note if you like (Alt+Shift+M).
  2. Right-click a page, a link, an image or selected text: Save to MyBrain. Selected text goes along as the note.
  3. Alt+Shift+S saves the page straight away. A ✓ on the button says it worked.

Change the keys at edge://extensions/shortcuts.
