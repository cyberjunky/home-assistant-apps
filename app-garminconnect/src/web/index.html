Fetching
Data sets

Data sets are switched on and off on the app's Configuration tab in Home Assistant. The history of a set goes back to the day your Garmin account was made (or the start date you set there), newest first, a piece at a time.

Data
Daily values (CSV) Activities (CSV) Database backup

Every answer from Garmin is kept, so a later version of this app can read more out of it without asking Garmin again. The backup holds everything; your Garmin sign-in is stored apart and is never part of a download.

Danger zone

Deletes everything fetched from Garmin. Your sign-in stays, and the whole history is fetched again from the start. Download a backup first; this cannot be undone.
