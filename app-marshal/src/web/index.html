Give a GitHub repository, as the Marketplace shows it. Marshal downloads its latest release, reads the code without running it, and scores it like an installed integration.

What Marshal does

Custom integrations run inside Home Assistant with all of its rights: they can read every credential, every entity and every file Home Assistant can. The Marketplace lists them; it does not test or audit them. Marshal reads the code of each integration and points at what deserves a second look.

How it reads code

Python files are parsed to a syntax tree and searched for patterns. Nothing from an integration is imported or run. The manifest is read as JSON. Other files are only measured.

The five areas

    Scores and grades

    Each area starts at 100. A finding takes off points by severity: critical 60, high 30, medium 12, low 4, notes 0. The same finding in more places weighs more, up to twice. The overall score is the weighted average of the areas, and never more than 15 above the weakest one. With a critical finding the score is 45 at most. A is 90 and up, B 80, C 65, D 50, below that F.

    What a finding is, and is not

    A finding is a lead, not a verdict. Marshal sees what code could do, not what it does. A notification integration posts to a chat service on purpose. A camera integration turns certificate checks off because the camera has a self-signed certificate. A low score says "read this one before you trust it", not "this is malicious".

    Packages from PyPI

    Most of what a cloud integration does on the network is in the library it installs. Each direct requirement is downloaded from PyPI and read the same way, without installing it. A package gets its own grade; only its high and critical findings count against the integration, and its hosts are added to the integration's. Packages that Home Assistant itself ships are skipped, and what a package in turn requires is not followed.

    And a high score is not a guarantee. Code that hides well, compiled code, the requirements of requirements, and front-end JavaScript are outside what Marshal reads.
